Knowledge and limits

Source-only preview uses fixed wording. Model chat requires a separate API key and explicit local configuration. Neither mode has the full omniQ knowledge library or production approval.

Chats stay in server memory for up to one hour and are not written to disk. Reloading starts a new chat. No ticket import is available here.

How to judge an answer

Check that the answer addresses the issue, uses the right product/version, supports its advice with sources, remembers your answers and escalates when needed.

Use “unsure” when you cannot verify the advice. A short answer is not necessarily a correct answer.
